# OpenCode Agent Production Pack

This directory contains OpenCode-native skills and reusable templates from `agent-production-skill-pack` v2.0.

- `skills/<name>/SKILL.md` follows the OpenCode skill format.
- `templates/` contains reusable issue, handoff, PR, QA, service inventory, and subagent assignment templates.
- Source pack: `agent_production_skill_pack_v2`.

These files are agent-operational guidance only; they do not change product/runtime behavior.
